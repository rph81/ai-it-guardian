Fix / Mode.

Guardian proposes fixes from tested recipes. An admin approves each one with a passkey. Every change is backed up first and rolled back if the check fails. Fixes apply to Guardian's own network (other sites follow with their collector).

    Proxmox snapshots (optional)

    A Proxmox API token that may only take and roll back snapshots: Datacenter › Permissions › Roles › Create GuardianSnapshot with VM.Snapshot, VM.Snapshot.Rollback, VM.Audit; user guardian-fix@pve, API token snapshots (privilege separation on), give the token that role on the guests.

    Windows (WinRM, agentless)

    A separate account in the machine's local Administrators group (installing updates and changing the firewall need it), used only for approved fixes. WinRM over HTTPS (5986) must be on. Not the read-only Windows connector account.

    Microsoft 365 fix app

    A separate app registration (e.g. Guardian-Fix), not the read-only Microsoft 365 connector. Application permissions, nothing else: . Grant admin consent. Guardian refuses an app with other permissions.

    NinjaOne patch jobs

    A second NinjaOne API client (e.g. Guardian-Patch) with the Management and Control scopes, used only for approved patch jobs. The read-only NinjaOne connector (Settings › Connectors) stays separate.
