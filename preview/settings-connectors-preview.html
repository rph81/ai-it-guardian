Suggested · new device

Connect Synology DSM

Guardian signs in with a read-only account and only reads settings.

  1. On the NAS: Control Panel → User & Group → Create a user called guardian-ro.
  2. Don't add it to administrators. Give it no share access and deny all applications except DSM.
  3. Paste its name and password below. Guardian checks it can't change anything before saving.
Verify the certificate (turn off for the self-signed certificate on this NAS)
Test passed: DSM 7.1-42962 · account is read-only · 2-factor status readable
Suggested

Connect Proxmox VE

  1. Datacenter → Permissions → API Tokens → Add: user guardian@pve, token read, privilege separation on.
  2. Give the token the built-in PVEAuditor role on /. That role can only read.
  3. Paste the token ID and secret below.
Standard connector · you can add several

Add Active Directory

  1. Create a normal domain user, e.g. svc-guardian. Domain Users membership is enough to read the directory.
  2. Set its password to never expire, or note the date: Guardian warns you before it expires.
  3. Use LDAPS (port 636) so the password is encrypted on the network.
