AI agents

After the network scan, a team of Claude agents analyses the results. Each specialist looks at one part of your IT, can run only the read-only checks listed on its card, and writes findings into the report.

How an assessment runs

Step 1 · program
Network scan
Finds devices, ports, services, web pages, certificates, UPnP and what the internet sees. No AI, free.
Step 2 · AI agent
Discovery
Works out what every device is: type, vendor, model, role, OS and firmware.
Step 3 · AI agent
Orchestrator
Decides which specialist looks at which devices, so nobody wastes time on irrelevant ones.
Step 4 · 5 AI agents, 3 at a time
Specialists
NetworkOS & endpointsWeb & APIsFirmwareInternet perimeter
Step 5 · AI agent
Report writer
Scores the site, writes the summary and the fix-first list in plain language.

What agents can never do

No shell, no commandsAgents only call the fixed checks above; they can't run anything else.
Your network onlyEvery address is checked against the scanned network before a probe runs.
No logins, no changesWeb requests are GET/HEAD without credentials; probes are non-intrusive.
No access to the vaultAgents never see connector passwords or your API key.
