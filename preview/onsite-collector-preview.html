  1. On a Linux host or VM at the customer (Docker installed, 2 GB RAM), run:
docker run -d --name guardian-collector --restart unless-stopped \ --network host --cap-add NET_RAW --cap-add NET_ADMIN \ -v guardian-collector:/data \ ghcr.io/rph81/guardian-collector:1.0.0 \ enroll https://collect.hadife.com XXXX-XXXX-XXXX \ --scope 10.30.0.0/24,10.30.1.0/24

Decisions for you

Before building phase A

Reaching the server

Cloudflare Tunnel to collect.hadife.com (recommended: no port forward at home), or a port forward to the gateway port only.

First package

Docker image (recommended), then a ready VM for Proxmox / Hyper-V / VMware, later a Pi image.

Customer credentials

Sealed to the collector (recommended: entered in the console, only that collector can open them) or entered only on the collector itself.
