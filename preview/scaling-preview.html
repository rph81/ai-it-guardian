Agents / Scaling.

For big environments: run several copies of a specialist in parallel, each on its own share of the devices.

Mode

Guardian decides how many copies of each agent to run from the number of devices it assigns, within the limits below.

Devices per agent copy (automatic mode)

25 devices per copy: fewer means faster and more thorough, but more copies cost more.

Total agents running at the same time

6 at once. Higher finishes sooner; the API rate limit of your plan is the ceiling.
