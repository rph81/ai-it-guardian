AI IT Guardian / Fix

Patching & fixes

Two parts: (1) Guardian reads patch status from your RMM and can ask it to install missing updates; (2) more fixes Guardian makes itself, each with a backup, a check and a rollback. Every change still needs remediation switched on and your passkey per change.

Part 1 · Settings › Connectors › RMM

RMM connector

NinjaOne ▾ (also: Datto RMM, N-able N-sight, Action1, Atera, ConnectWise Automate)
API client, read-only scopes · used by every assessment
Used only while remediation is on, for approved jobs

What the agents get

  • Every managed device, even when off the office network
  • Missing patches per device with KB / CVE, severity, release date
  • Pending reboots, failed installs, last patch scan
  • AV / EDR status, disk encryption, OS version

The Patch & configuration and Device fleet agents use this, and the Risk analyst ranks missing patches with KEV / EPSS like the rest.

Decisions for you

Before building

Which RMM?

I'll build the one you (or your first customers) use first. Common for MSPs: NinjaOne, Datto RMM, N-able, Atera, ConnectWise Automate; Action1 if you only want patching.

Microsoft 365 fixes

Need a separate "Guardian-Fix" app with a few write permissions (mail rules, user enable/disable, Conditional Access), used only while remediation is on. Include them?

First batch

Suggested: Linux security updates + auto updates, the three Windows fixes, the M365 fixes, then the RMM patch jobs.
